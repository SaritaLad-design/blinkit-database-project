# Blinkit Database Design Project

## Project Overview
This project focuses on designing a relational database schema for Blinkit, an online grocery delivery platform.

## Tools Used
- ER Diagram
- Database Schema Design

## Features
- Customer Management
- Order Tracking
- Product Inventory
- Delivery Partner Management
- Payment Handling

## Database Entities
- Customers
- Orders
- Products
- Delivery Partners
- Payments

## Relationships
- One-to-Many
- Many-to-One
- Many-to-Many

## Project Files
- Word Documentation
- ER Diagram
- Schema Design

## Conclusion
This project demonstrates relational database design and business workflow structuring for an e-commerce platform.
